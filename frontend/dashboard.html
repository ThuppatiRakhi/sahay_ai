      Install SahayAI Chrome Extension

      During development, the SahayAI extension can be loaded directly from your repository in Google Chrome Developer Mode:

      1. Open Chrome Extensions: Navigate to chrome://extensions/ in your browser.
      2. Enable Developer Mode: Toggle on the Developer mode switch in the top right corner.

      4. Select Folder: Select the browser_extension folder in your SahayAI codebase.
      Notice: The extension is in active local development and has not yet been published to the Chrome Web Store.
